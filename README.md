# Nightfall 3D 🔪 — لعبة رعب 3D أونلاين

قاتل واحد ضد ناجين (لين 6). الناجين يصلحون المولدات، تنفتح البوابات، ويهربون. القاتل يلاحقهم.

## كيف تلعبون
- **الكاميرا:** اسحب بإصبعك على الجهة اليمين (أو بالماوس) عشان تدوّر الكاميرا. الحركة دايماً نسبة لاتجاه الكاميرا، والقاتل يضرب باتجاه الكاميرا.
- **الجودة:** زر "الجودة" فوق: منخفضة / متوسطة / عالية (الظلال الحقيقية). الجوال يبدأ على متوسطة، وتنخفض الجودة تلقائياً لو الأداء ضعيف (إلا لو اخترتها بنفسك).
- **الناجي:** حرّك بالجويستك (يسار الشاشة) وقف عند مولد واضغط وامسك زر "تصليح / إنقاذ". لو واحد من ربعك طاح، امسك الزر جنبه 5 ثواني وتنقذه.
- **القاتل:** اقترب من ناجي واضغط "هجوم". ضربتين تطيّح الناجي، وضربة ثالثة تقتله. لو تركته ينزف 45 ثانية يموت لحاله.
- عدد المولدات المطلوبة يتغير حسب عدد الناجين (3 ناجين = 4 مولدات).
- على الكمبيوتر: WASD للحركة، Space أو E للزر.
- القاتل يتحدد عشوائي كل جولة. أول واحد دخل الغرفة هو اللي يبدأ اللعبة.

## التشغيل على جهازك (للتجربة)
1. نزّل Node.js (النسخة 18 أو أحدث).
2. افتح الترمنال داخل المجلد:
   ```
   npm install
   node server.js
   ```
3. افتح `http://localhost:3000` في المتصفح.
   لو ربعك على نفس الواي فاي: افتحوا `http://IP-جهازك:3000`.

## ليلعب ربعك من أي مكان (استضافة مجانية)
1. ارفع المجلد على GitHub (ريبو جديد، بدون مجلد `node_modules`).
2. على **render.com**: New → Web Service → اربط الريبو.
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - الخطة: Free
3. بعد النشر يعطيك رابط مثل `https://nightfall-xxxx.onrender.com`. افتحه من الآيفون، ويفتحه ربعك، وتدخلون نفس كود الغرفة.
   (الخطة المجانية تنام بعد فترة بدون استخدام، أول فتح ياخذ نص دقيقة.)

على الآيفون: افتح الرابط في Safari ← زر المشاركة ← "إضافة إلى الشاشة الرئيسية" عشان يشتغل ملء الشاشة مثل التطبيق.

## تطبيق الآيفون (IPA عن طريق Sideloadly)
التطبيق غلاف بسيط يفتح اللعبة ملء الشاشة بالعرض، ويشغّل الصوت حتى لو الجوال على الصامت.
1. ارفع كل المشروع (مع مجلد `ios` ومجلد `.github`) على GitHub.
2. روح تبويب **Actions** ← **Build IPA** ← **Run workflow**. بعد ما يخلص (كم دقيقة) نزّل الملف من **Artifacts** (`Nightfall-ipa`) وفك الضغط تلقى `Nightfall.ipa`.
3. ثبّته بـ **Sideloadly** مثل بقية تطبيقاتك.
4. أول مرة تفتح التطبيق يطلب **رابط السيرفر** (رابط Render اللي فوق). لتغييره بعدين: **هز الجوال**.

> السيرفر لازم يكون شغال (Render أو جهازك) عشان يشتغل الأونلاين. التطبيق نفسه ما يحتاج تحديث لما نعدل اللعبة، لأنه يحمّلها من السيرفر كل مرة.

## هيكل المشروع
- `server.js` — السيرفر: الغرف، الحركة، الضرب، المولدات، الهروب.
- `public/index.html` — اللعبة بـ3D (three.js): المشهد، الإضاءة والضباب، الكاميرا، التحكم باللمس، الصوت والموسيقى (كلها مولّدة بالكود).
- `public/assets/chars/` — الشخصيات الخمس (GLB مع هيكل Mixamo)، و`public/assets/anims/` — الحركات (idle, walk, run, sprint, hide, crouchwalk, attack, injured, dying).
- `tools/characters/` — سكربتات Blender اللي جهزت الشخصيات (تنظيف، ريق، تصدير الحركات).
- `public/vendor/` — مكتبة three.js (محلية، ما تحتاج نت خارجي).
- `public/map.js` — الخريطة (نفس الخريطة عند كل اللاعبين).
- `ios/` — مشروع تطبيق الآيفون، و`.github/workflows/build-ipa.yml` يبنيه.

## المراحل الجاية (اقتراح)
- خطاطيف وتعليق الناجين، وقدرات للشخصيات، وخرائط أكثر.
- زر الاختباء (حركات hide و crouchwalk جاهزة)، ومؤثرات أكثر.
